# Файл середовища та правила Git ignore

## Головна ідея

**`.env`** зберігає **секрети та параметри середовища** (ключі API, порти) для локального чи розгорнутого сервера. **`.gitignore`** вказує Git, які згенеровані або чутливі шляхи **ніколи не комітити**, зокрема `.env` і встановлені залежності.

## Детальніше

### `.env`

У репозиторії немає закоміченого `.env` (він ігнорується). Під час роботи сервер очікує певні змінні, коли ввімкнені відповідні функції — наприклад ключі OpenAI або Gemini для reasoning, опційно **`PORT`**. Якщо ключів немає, сервер може стартувати, але частина маршрутів впаде або залогає попередження.

Типові категорії значень:

- **Порт HTTP** — перевизначає порт за замовчуванням.
- **Ключі провайдерів** — увімкнюють серверний reasoning чи опис зображень.
- **Інші секрети** — webhook, БД, сторонні сервіси.

### `.gitignore`

Файл виключає:

- **`node_modules/`** — відновлюються через `npm install`.
- **`.env`** — запобігає витоку секретів.
- **Логи та сміття ОС** — `*.log`, `.DS_Store` тощо.

## Функціональні деталі

| Артефакт | Функція |
|----------|---------|
| `.env` | Заповнює `process.env`, щоб Node міг автентифікуватися в зовнішні API і слухати потрібний порт без секретів у коді. |
| `.gitignore` | Менший ризик витоку облікових даних; великі локальні дерева не потрапляють у Git. |

**Експлуатація:** у кожного розробника чи середовища свій `.env`. Перелік змінних документуйте окремо; сервер натякає в логах, якщо опційні ключі (наприклад OpenAI) відсутні.

## Code

### `.gitignore` (корінь репозиторію)

**Зміст (навзаєм):**

- **`node_modules/`** — усі встановлені пакунки на будь-якій глибині.
- **`.env`**
- **`*.log`**, **`.DS_Store`**

**Змінні / параметри:** немає — лише шаблони рядків.

**Хто використовує:** Git; під час runtime не імпортується.

### `.env` (не в репозиторії)

**Формат:** рядок на змінну `KEY=value`; коментарі з `#`.

**Споживачі (через `process.env`):**

- **`server/main.js`** — **`PORT`** (за замовчуванням 3001); наявність **`OPENAI_API_KEY`** (у лог лише маска).
- **`lib/cloud/reasoning-server.js`** — відкладене читання **`OPENAI_API_KEY`**, **`GEMINI_API_KEY`** для клієнтів OpenAI / Google GenAI.
- **Інші cloud-модулі** — будь-який виклик `process.env.*` після ініціалізації.

### Завантаження — `lib/cloud/action-servers/api-server.js`

| Символ | Роль |
|--------|------|
| `loadEnvFile(filePath)` | **Синхронно** читає `.env`, парсить `KEY=value`, знімає лапки, пише в **`process.env[key]`** лише якщо ключ ще не заданий. |
| `envPathV4` | шлях до `.env` біля кореня v4 (поруч із `config/`). |
| `envPathRoot` | на рівень вище (legacy / monorepo). |
| `loadedV4` / `loadedRoot` | якщо хоч один успішний — лог **`.env file loaded`**. |
| Fallback | **`require('dotenv').config`** на тих самих шляхах у `try/catch`. |

**Ланцюжок:** `setupApiServer(app)` викликається з **`server/main.js`** поряд з іншим налаштуванням; середовище має бути завантажене до обробки запитів **`setupReasoningServer`**.

**Залежності:** **`.gitignore`** не дає закомітити `.env`; **`package.json`** містить **`dotenv`** для fallback.
