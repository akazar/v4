# `node_modules`

## Головна ідея

**`node_modules/`** — каталог, куди **npm встановлює пакунки** з `package.json`, включно з транзитивними залежностями. Це дискове представлення графа залежностей, зафіксованого в `package-lock.json`.

## Детальніше

У `node_modules` немає власного коду проєкту. Там сторонні бібліотеки:

- HTTP-сервер і middleware
- WebSocket / realtime
- Обробка зображень і рантайми моделей
- HTTP-клієнти для AI-провайдерів
- Утиліти для стримінгу, конфігурації та інструментів

Каталог **великий** і **перегенеровується** через `npm install` у корені. Виключений з Git через `.gitignore`.

## Функціональні деталі

| Аспект | Роль |
|--------|------|
| **Інсталяція** | Заповнюється `npm install` за lockfile. |
| **Runtime** | Node резолвить `import` / `require` у ці пакунки під час роботи сервера чи скриптів. |
| **Сайт docs** | У `apps/docs` — **окремий** `node_modules` після `npm install` там. |
| **Чистий стан** | Видалення `node_modules` і повторна інсталяція часто лагодить пошкоджені або роз’їхані версії. |

**Навіщо документувати:** ставитися до `node_modules` як до **артефакту збірки** — не редагувати вручну, не комітити; відмінності між машинами зазвичай через версію npm або зміни lockfile.

## Code

### Алгоритм резолву (Node + npm)

| Крок | Поведінка |
|------|-----------|
| `import 'express'` | Node шукає `node_modules/express`, рухаючись вгору від файлу, або використовує hoisted layout. |
| **Hoisting** | Транзитивні залежності можуть бути у кореневому `node_modules` або вкладеному. |
| **Lockfile** | Мапа **`packages`** у `package-lock.json` задає **версію** і **місце** кожного пакунка. |

### Зв’язок із кодом проєкту

Жоден файл проєкту не імпортує `node_modules` як шлях — лише **bare specifiers** (`express`, `openai`, …).

**Використовують:**

- **`server/main.js`** — `express`, `http`.
- **`lib/cloud/**`** — залежно від модуля: `openai`, `@google/genai`, `socket.io`, `puppeteer`, …
- **`apps/docs`** — окреме дерево: `@docusaurus/*`, `react` з **`apps/docs/node_modules`**.

### Змінні та артефакти

| Назва | Значення |
|-------|----------|
| **Тека пакунка** | Напр. `node_modules/express/package.json` — **main**, **exports**, **dependencies**. |
| **.bin** | Обгортки CLI для dev-інструментів. |

**Логіка:** після **`npm install`** запуск **`node server/main.js`** синхронно резолвить усі `import` у файли під **`node_modules`** за правилами ESM Node.
