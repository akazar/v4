# Vision v4 — документація проєкту

**Vision v4** — платформа розпізнавання об’єктів і міркувань щодо зображень. Поєднує детекцію в браузері (YOLO і MediaPipe), опційне серверне розпізнавання та vision–language reasoning (OpenAI і Google Gemini), перегляд кількох потоків через WebRTC, інструменти конфігурації, експорт анотацій і симульований робочий простір для «навчання» моделей.

Сайт описує **призначення кожної частини репозиторію** і **поведінку користувацьких застосунків**. На кожній сторінці з деталями в кінці є розділ **Code** (і вкладені **###** теми) з посиланнями на реалізацію: точки входу, ключові символи, параметри та зв’язки між каталогами.

## Як усе зібрано докупи

- **Node-сервер** (`server/`) обслуговує статичні веб-застосунки з `apps/`, надає REST для розпізнавання, міркувань, конфігурації, сповіщень, допоміжних операцій з БД, метаданих стримінгу, експорту анотацій, файлів model-training і працює з **Socket.IO** для сигналінгу WebRTC.
- **`lib/`** — спільна логіка: **edge** (захоплення в браузері, оверлеї, дії) і **cloud** (серверні конвеєри, стримінг, оркестрація).
- **`config/`** — JavaScript-об’єкти конфігурації: моделі, інтервали, стилі, декларативні чи скриптові дії для локальних і серверних конвеєрів.
- **`factory/web/`** — демо «як у продакшені» за адресою `/factory`, керується factory-конфігом.
- **`apps/`** — усі браузерні інтерфейси: лендінги, стримінг, анотатор, навчання, compare тощо.

## Code

### Точка входу процесу

| Шлях | Роль |
|------|------|
| **`server/main.js`** | **`npm start`** — підключає Express, HTTP-сервер і всі виклики **`setup*Server(app|server)`** з **`lib/cloud/**`**. |
| **`package.json`, поле `main`** | Вказує на **`server/main.js`** для інструментів, що читають **`main`**. |

### Підключення модулів у браузері

Статичний **`express.static(v4Root)`** у **`server/hosting-server.js`** віддає **`/lib/…`** і **`/config/…`**, тож **`import '/lib/edge/…'`** і відносні **`../../config/…`** працюють без бандлера.

### Структура документації

Сторінки категорій **[Корені репозиторію](./project/package-manifests)**, **[Бекенд і спільні ресурси](./project/server)** та **[Застосунки](./apps/overview)** містять **## Code** після описової частини — користуйтеся боковою панеллю.

### Лише сайт документації

**`apps/docs/`** не імпортується під час виконання; має власні **`package.json`** і lockfile. Після **`npm run docs:build`** у корені репозиторію основний сервер віддає зібраний сайт за **`/documentation/`** на тому ж хості й порту, що й **`npm start`**. Для редагування з гарячим перезавантаженням використовуйте **`npm run docs:dev`**.
