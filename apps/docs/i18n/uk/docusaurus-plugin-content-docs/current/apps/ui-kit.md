# Спільний UI kit (`apps/ui-kit`)

## Головна ідея

**`apps/ui-kit/ui-kit.css`** — **спільний шар дизайну** для браузерних апок Vision v4. Змонтований за **`/ui-kit`**, тож сторінка може підключити **`/ui-kit/ui-kit.css`** і отримати узгоджені кольори, типографіку, відступи та стилі компонентів.

## Детальніше

UI kit — **не** окремий застосунок з власним сценарієм; це **модуль стилів**, який споживають лендінг, стримінг, навчання, конфіг-тули, compare тощо.

## Функціональні деталі

| Функція | Користь |
|---------|---------|
| **Візуальна узгодженість** | Кнопки, панелі, посилання виглядають «з однієї системи». |
| **Швидша верстка** | Нові апки підключають токени без копіювання CSS між теками. |
| **Теми** | Центральні CSS-змінні спрощують dark/light або бренд. |

## Сценарії користувача

Окрім автоматичного застосування стилів при відкритті сторінки з посиланням на kit, **окремого UX немає**. Розробники змінюють kit для **глобального** оновлення вигляду.

## Code

### `apps/ui-kit/ui-kit.css`

**Роль:** **design tokens** на `:root`, reset, утиліти типографіки, кнопки, форми, картки — підключення через **`<link href="/ui-kit/ui-kit.css">`**.

**Параметри:** немає (не скрипт). **Селектори** — спільні класи (наприклад `.btn`).

**Хостинг:** **`express.static`** на **`/ui-kit`** → **`apps/ui-kit`** у **`hosting-server.js`**.

**Хто підключає:** `apps/landing`, `camera-stream`, `config-creator`, `streaming` тощо — пошук **`ui-kit.css`** у `apps/**`.
