# VIA image annotator (`/annotate`)

## Головна ідея

**`/annotate`** віддає пакет **VGG Image Annotator (VIA)** — **автономний** ручний інструмент для **зображень, аудіо та відео** в браузері. Призначений для датасетів під навчання, оцінку чи документацію, а не для автоматичного інференсу.

## Детальніше

Повна панель керування VIA (тулбар, canvas, атрибути, імпорт/експорт). Гарячі клавіші описані в самому застосунку.

## Візуальні елементи (групами)

- **Верхня панель** — файли, проєкт, режими, вигляд.
- **Canvas / медіа** — просторові регіони (рамки на кадрах тощо).
- **Редактор атрибутів** — мітки та метадані для регіонів або часових сегментів.
- **Імпорт / експорт** — VIA CSV, лише тимчасові сегменти CSV, COCO, імпорт shared project / VIA2 JSON.
- **Статус / довідка** — підказки та шорткати.

## Сценарії користувача

### Зображення

1. Завантажити медіа (локально або URI, масовий paste).
2. Малювати регіони (рамки тощо).
3. Заповнити атрибути.
4. Експорт COCO або VIA для пайплайнів.

### Відео

1. Завантажити кліп; **pause** на потрібних кадрах.
2. Регіони на кадрах; навігація шорткатами.
3. Експорт структурованих міток.

### Аудіо

1. Завантажити аудіо; **тимчасові сегменти** (початок/кінець).
2. Теги сегментів.
3. За потреби експорт CSV сегментів.

**Інтеграція:** сервер може мати **endpoint експорту**, щоб COCO зберігався в теку репозиторію — зручно, коли анотатори на тому ж хості, що й Vision v4.

## Code

### `apps/annotate/index.html`

**Монолітний VIA** — інлайн **`<style>`**, великі інлайн **`<script>`** з глобалями **`via_*`**, машиною стану, імпортом/експортом. Не ESM, крім додатків нижче.

**Додаткові скрипти проєкту:**

- **`annotate-sidecar-image.js`** — **`window.annotateCollectSidecarImage(via)`**, base64 поточного кадру через **`via.va.file_annotator`**, мапа MIME → розширення.
- **`annotate-file-panel.js`** — ES module; ліва панель: **`GET /api/annotate/annotation-list`**, **`DELETE …/:name`**.

### `apps/annotate/annotate-file-panel.js`

| Символ | Роль |
|--------|------|
| **`LIST_URL`** | **`/api/annotate/annotation-list`**. |
| **`deleteUrl(name)`** | шлях для DELETE з **`encodeURIComponent`**. |
| **`displayFileName`** | прибирає **`.json`** лише для підписів UI. |
| **`fetchList` / `deleteFile`** | JSON; помилки з **`data.error`**. |
| **`el`** | фабрика DOM-вузлів. |

### `apps/annotate/annotate-sidecar-image.js`

IIFE; **`annotateCollectSidecarImage`** повертає Promise з полями **`base64`**, **`mime`**, **`extension`** для пари sidecar на сервері; залежить від **`_VIA_FILE_TYPE`**, **`_VIA_FILE_LOC`**.

### Сервер

**`server/services/annotate-export-service.js`** — прийом експортів у **`apps/annotate/annotation-list`**; список і delete для панелі.
