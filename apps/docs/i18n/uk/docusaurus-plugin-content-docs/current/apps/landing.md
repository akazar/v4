# Лендінги

## Головна ідея

**Лендінг** — **маркетинговий і навігаційний хаб** Vision v4. Англійська версія за **`/`**; українська — за **`/ua`**. Обидві коротко описують платформу й ведуть у всі основні модулі.

## Детальніше

### Візуальні елементи (англійський `/`)

- **Перемикач мови** — поточна мова (`EN`) і посилання на українську сторінку.
- **Hero** — заголовок, підзаголовок, блок **«All features»** з сіткою карток-посилань.
- **Міні-картки** — іконка + підпис: production demo, стримінг, config manager, config generator, camera stream, image upload, дашборд моделей, навчання, анотатор, compare, server detection, server reasoning.
- **Огляд системи** — текст про realtime, пакетні зображення, серверні сценарії, кастомізацію, дії, робочий простір навчання.
- **Картки модулів** — можливості, use case, інколи workflow для кожного великого модуля.
- **Технічна сітка** — модель, конфігурація, архітектура, API.
- **Футер** — брендинг / версія.

### Візуальні елементи (український `/ua`)

Та сама структура з українським текстом і посиланням назад на EN.

## Сценарії користувача

1. **Ознайомлення** — відкрити `/`, переглянути hero та огляд.
2. **Перехід до інструмента** — клік по міні-картці або CTA в модулі.
3. **Швидкий вибір** — розгорнути «All features» для компактної сітки.
4. **Мова** — перемикач у шапці між EN і UA.

**Результат:** не потрібно пам’ятати URL — лендінг є **єдиною картою** системи.

## Code

### `apps/landing/index.html`

- **Head** — viewport; стилі **`/ui-kit/ui-kit.css`**, **`styles.css`**.
- **Body** — **`<nav class="lang-switcher">`**, **`.hero`** з **`<details class="features-accordion">`** і **`.features-cards-grid`** посилань, **`<main>`** з **`.intro`**, **`.features`**, **`.modules`** (**.module-card**, **.cta-button**), **`.footer`**.

**Без JavaScript** — лише HTML + CSS; шляхи захардкоджені (`/streaming`, `/factory/web` тощо).

### `apps/landing/ua/index.html`

Той самий каркас, український текст, посилання на **`/`**.

### `apps/landing/styles.css`

Стилі hero, акордеону, сітки, карток, типографіка. **Лише** для лендінгу.

**Віддача:** **`server/hosting-server.js`**; **немає** import з `lib/`.
