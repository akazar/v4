# Веб-демо Factory (`apps/factory` → `/factory`)

## Головна ідея

**Factory web demo** — **односторінковий конфіг-керований** досвід із повним **локальним** vision-конвеєром: камера, інференс (YOLO або MediaPipe за конфігом), опційні екранні кнопки й налаштовані дії.

## Детальніше

Тіло HTML **навмисно порожнє** — логіка в скриптах. ONNX підвантажується для YOLO. Конфіг отримують за ідентифікатором з URL, щоб можна було зберігати закладки на профіль.

## Візуальні елементи

- **Камера на весь екран** — відео як основне полотно.
- **Опційна верхня смуга імені** — якщо в конфігу є ім’я й увімкнено UI.
- **Опційна нижня панель** — **ON** / **OFF** і події для демо чи автоматизації.
- **Оверлей детекції** — рамки та підписи поверх відео.

## Сценарії користувача

1. Відкрити `/factory` або `/factory/<configId>` (або з лендінгу / config manager).
2. Дозволити доступ до камери.
3. Спостерігати оновлення рамок за інтервалом з конфігу.
4. За наявності керування — ON/OFF для паузи/відновлення поведінки.
5. Змінити конфіг у Generator або в `config/public`, перезавантажити з новим id.

**Результат:** один еталонний приклад того, як конфіг керує поведінкою «як у проді».

## Code

Див. **[factory — Code](../project/factory#code)** для **`apps/factory/script.js`**: **`fetch /api/configurations/:id`**, **`initApp`**, **`injectTopButtons`**, **`startRecognitionLoop`**.

### `apps/factory/index.html` (коротко)

CDN **`ort.min.js`**, модуль **`script.js`**. Без інлайн-UI — той самий підхід, що й **`apps/debug`**.

### Відмінності від `apps/camera-stream`

| Аспект | Factory | Camera stream |
|--------|---------|----------------|
| **Джерело конфігу** | **GET `/api/configurations/:id`** (query **`id`**) | Статичний **`import '../../config/config.js'`** |
| **UI** | **`injectTopButtons` + `ui:state`** | Явні кнопки в HTML і `script.js` |
| **Розташування** | `apps/factory`, URL **`/factory`** | `apps/camera-stream` |
