Conveyor POC

Pick a saved configuration, click Run pipeline, and the generator will produce edge + server artifacts as a single ZIP bundle.

1. Configuration

Lists files in config/public/. Create new ones in config-creator-adv.

2. Run pipeline

Generates a single ZIP named <configId>.zip. Inside it, all artifacts live under a <configId>/ folder — unzip and deploy the whole folder as-is.

3. How to run

Pick a configuration and click Run pipeline to see the commands tailored to it.
