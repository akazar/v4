Model training UI preview

Prepare detection or vision–language fine-tuning jobs: set the output checkpoint name, choose a base model, upload images and annotation files, assign splits, tune hyperparameters, and review live metrics. Open the saved models dashboard to list or remove checkpoints in models-list.

1. Trained model name

This name becomes the file name of your exported or saved checkpoint (extension is chosen from the base model: .pt, .tflite, or .safetensors). Letters, numbers, dots, underscores, and hyphens only; a typed extension is replaced automatically.

2. Base model

Pick a checkpoint family. Listed options are placeholders for your registry.

3. Images & annotations

Add image files (e.g. JPG, PNG). Add matching annotation files (JSON, XML, TXT) — pairs are matched by filename without extension (same stem as the image).

4. Train / validation / test

Assign each row to a split. Use auto-split to distribute rows in file order.

7. Export & save model

      

        After a full run, download the trained checkpoint to your machine, or save it under
        apps/model-training/models-list on the host (serve this app with the v4 Node server so save works).
        The file name follows section 1: trained model name plus the extension that matches the base model type.
