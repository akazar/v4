System Overview

The Vision System is a comprehensive object recognition platform that leverages cutting-edge machine learning models to detect and identify objects in real-time camera streams and static images. Built with MediaPipe's EfficientDet Lite2 model, the system provides accurate, fast, and configurable object detection capabilities.

The platform is designed with a modular architecture, allowing for easy configuration of detection classes, thresholds, and custom action functions. It supports both real-time processing from camera feeds and batch processing of uploaded images, making it suitable for a wide range of applications including security monitoring, content analysis, and automated object tracking.

Key Features

  • Real-time Object Detection: Process live camera feeds with configurable recognition intervals
  • Batch Image Processing: Upload images from files or URLs for analysis
  • Server Detection: Run recognition via the server API (Puppeteer + MediaPipe) and view results in the browser
  • Server Reasoning: Send an image and prompt to the server for AI reasoning (ChatGPT or Gemini) and view the response
  • Customizable Detection Classes: Configure which object types to detect (persons, vehicles, animals, etc.)
  • Bounding Box Visualization: Visual feedback with customizable bounding boxes and labels
  • Action System: Execute custom functions based on detection results
  • OpenAI Integration: Optional AI-powered image description capabilities
  • Modular Architecture: Easy to extend and customize for specific use cases
  • Model Training Workspace: Browser UI to stage detection or VLM fine-tuning jobs, dataset splits, and simulated live metric charts (training, saved models)

Production Demo

Flexible configuration
Launch Demo

Flexible Functionality Configuration — Web Version

A single-page production demo that runs the full vision pipeline from your browser using config-factory.js. Switch between YOLO and MediaPipe, control recognition and regular actions, and toggle the UI—all driven by one configuration file.

Capabilities:

  • Config-driven: Behavior is defined by config-factory.js (classes, thresholds, model, actions)
  • Dual model: Choose YOLO or MediaPipe for local object detection
  • Camera stream: Live camera feed with bounding boxes and configurable recognition interval
  • Local actions: Recognition action functions and regular (periodic) action functions with throttling
  • Optional UI: Show/hide control buttons via config.ui; headless mode for automation

Use Cases:

  • Try the platform with the reference configuration
  • Validate config changes before deploying to other modules
  • Demo or testing of the flexible configuration web version

Use the Config Generator to build a custom config.js, then replace config-factory.js or point the demo to your config for a tailored experience. Use the Config Manager to list, view, and delete configs in config/public.

Multi-Stream WebRTC

Launch Streaming

WebRTC Streaming with Capture & Recognition

The Streaming module lets you create multiple WebRTC video streams from device cameras or video URLs, view them together on a single page, and capture frames for object recognition using YOLO or MediaPipe — all in the browser via peer-to-peer connections.

Capabilities:

  • Camera Streams: Open streamer pages that broadcast your camera feed via WebRTC
  • URL Streams: Stream from a video file URL (MP4, WebM) instead of a camera
  • Multi-Viewer: Watch multiple streams side by side on a single viewer page
  • Capture & Recognize: Capture a frame from any live stream and run YOLO or MediaPipe detection with bounding boxes
  • Model Selection: Switch between YOLO and MediaPipe for captured frame recognition
  • QR Codes: Generate QR codes for streamer page URLs for quick mobile access

Use Cases:

  • Multi-camera monitoring with on-demand object detection
  • Streaming a video file and analyzing specific frames
  • Remote camera access from mobile devices via QR codes
  • Comparing recognition results across different camera angles

Workflow:

  1. Enter a stream ID (and optionally a video URL) on the home page, then open the streamer
  2. Start the camera or video on the streamer page
  3. Select active streams and open the viewer page
  4. Click Capture on any stream, choose a model, and view detection results

Config Generator

Open Config Generator

Create and Customize config.js

The Config Generator is a web-based tool that lets you build config.js for Vision v4 without editing files by hand. Set recognition classes, detection thresholds, model options, API settings, and more through a simple form, then copy or download the generated configuration.

Capabilities:

  • Recognition: Configure detection classes (e.g. person, dog, car), score threshold, and recognition interval
  • Model: Set model asset path, delegate (GPU/CPU), and score threshold
  • API: Configure base URL and describe prompt for OpenAI-style image description
  • Options: Tune other runtime and display options
  • Export: Copy the generated config or download it as config.js

Use Cases:

  • Quick setup of a new Vision v4 deployment
  • Experimenting with different detection classes and thresholds
  • Generating configs for different environments (dev, staging, production)

Camera Stream

Launch Camera Stream

Real-Time Object Recognition

The Camera Stream module provides live object detection from your device's camera feed. It continuously processes video frames and displays detected objects with bounding boxes overlaid on the video stream.

Capabilities:

  • Live Camera Feed: Access and display your device's camera stream as a background
  • Continuous Recognition: Automatically detect objects at configurable intervals (default: 500ms)
  • Manual Recognition: Trigger recognition on-demand for specific frames
  • Real-time Bounding Boxes: Visual overlay showing detected objects with confidence scores
  • Recognition Actions: Execute custom functions when objects are detected
  • Regular Actions: Periodic actions that run independently of recognition cycles

Use Cases:

  • Security monitoring and surveillance
  • People counting and tracking
  • Real-time object presence detection
  • Interactive applications requiring live visual feedback

Controls:

  • Start Camera: Initialize and display the camera stream
  • Stop Camera: Stop the camera feed and release resources
  • Start Recognition: Begin continuous object detection
  • Stop Recognition: Pause detection while keeping camera active
  • Manual Recognition: Perform a single recognition pass on the current frame

Model Training

Models dashboard Open training

Detection training & VLM fine-tuning workspace

The training app (/model-training) is a browser-based control room for preparing visual recognition training and vision–language model fine-tuning: pick a base model from a fixed list, upload images with sidecar annotation files, assign each sample to train, validation, or test sets, set common hyperparameters, and run a simulated job that streams placeholder metrics into live charts (loss, mAP, precision/recall, learning rate, and timing). The saved models dashboard (/model-training/dashboard) lists checkpoint files under apps/model-training/models-list and lets you remove them from disk via the v4 server API.

Capabilities:

  • Training UI: Predefined base models, dataset uploads, splits, hyperparameters, simulated metrics, export or save empty checkpoint files
  • Models dashboard: List .pt / .tflite / .safetensors in models-list; delete with trash control
  • Uploads: Multi-file images plus annotations; pairing by matching filename stems
  • Splits: Per-row train / validation / test, with optional auto-split presets
  • Simulated run: Timed epochs only — no GPU job — with updating charts

Use cases:

  • Prototype the training operator UX before wiring a real trainer
  • Manage saved placeholder checkpoints from the dashboard after a simulated save
  • Pair with VIA and Image Upload in documentation flows

Training is simulated on the client; saving checkpoints and the dashboard require the v4 Node server. Replace the timeout loop with a real trainer when you connect a backend.

VIA Image Annotator

Launch Annotator

Manual annotation for image, audio, and video

The bundled app is VGG Image Annotator (VIA) in its image-annotator variant: the same self-contained HTML/JS/CSS tool described in the app’s About page—manual labels for image, audio, and video, runnable in the browser without a separate install. Here it is served at /annotate on this host.

Capabilities:

  • Load media: Use local files or add files with file:// (local) or http:// (remote) URIs, or use bulk to paste one URI per line, choose Image / Video / Audio / auto-detect, and optionally import URIs from a text file
  • Spatial regions: Click and drag to draw regions (for example rectangular bounding boxes) on images and on video frames while the video is paused
  • Temporal segments: Mark time ranges on audio and video (for example from one timestamp to another)
  • Attributes: Open the attribute editor to define or update attributes (e.g. name, colour) on user-defined regions
  • Import / export: From the toolbar import/export dialog—export VIA3 (CSV), only temporal segments (CSV), or COCO; import a VIA shared project id or a VIA2 project JSON file
  • Shortcuts: Space plays or pauses audio/video; n / p move to next/previous image; full list (zoom, magnifier, region visibility, etc.) is under the in-app keyboard shortcuts help

Use Cases:

  • Ground-truth boxes, segments, and attributes for datasets or model evaluation
  • Labeling media before or alongside checks in Image Upload or Compare

Compare

Launch Compare

Local vs Server Recognition & Reasoning

The Compare module lets you upload one image and run local object detection (YOLO or MediaPipe) alongside server-side recognition and server-side AI reasoning (ChatGPT or Gemini). View results side-by-side for the same image.

Capabilities:

  • Single Image: Upload one image; all panels use it
  • Local Recognition: Run YOLO or MediaPipe in the browser (left/right panels)
  • Server Recognition: Run detection via the server API and view bounding boxes
  • Server Reasoning: Send the image to ChatGPT or Gemini and view the text response
  • Side-by-Side: Compare local vs server detection and reasoning in one view

Use Cases:

  • Compare local (YOLO/MediaPipe) vs server detection on the same image
  • Run recognition and reasoning in one place without switching apps
  • Evaluate model or API behavior with a single upload

Server Detection

Launch Server Detection

Object Recognition via Server API

The Server Detection module lets you run object detection on images using the recognition server. Load an image from file or URL; recognition is performed on the server (Puppeteer + MediaPipe), and results are displayed with bounding boxes. You can download the annotated image.

Capabilities:

  • File or URL: Load images from your device or from a web URL
  • Server-Side Recognition: Detection runs on the recognition server (no client-side model)
  • Result Visualization: Bounding boxes and labels overlaid on the image
  • Download: Save the annotated result as JPG

Use Cases:

  • Offloading heavy detection to a dedicated server
  • Testing the recognition server API from the browser
  • Batch or one-off image analysis without loading the model in the client

Requirements:

  • The recognition server must be running (e.g. npm run recognize or separate process on the configured port)

Server Reasoning

Launch Server Reasoning

AI Reasoning over Images

The Server Reasoning module sends an image and a text prompt to the server, which uses ChatGPT (OpenAI) or Gemini to reason about the image and return a text response. Choose the model, enter a prompt, and load an image to get AI-generated analysis or answers.

Capabilities:

  • Image + Prompt: Upload or paste an image and ask a question or request analysis
  • Model Selection: Use ChatGPT (e.g. gpt-4.1-mini) or Gemini (e.g. gemini-3-flash-preview)
  • Server-Side Reasoning: Vision-language reasoning runs on the server via OpenAI or Google APIs
  • Plain-Text Response: View the model's reasoning or answer in the browser

Use Cases:

  • Image description, captioning, or Q&A about image content
  • Visual reasoning and analysis without running models in the client
  • Testing the reasoning API (POST /api/reasoning) from the browser

Requirements:

  • Main v4 server running (reasoning API is part of the same server)
  • OPENAI_API_KEY and/or GEMINI_API_KEY set in .env

Technical Details

Model

MediaPipe EfficientDet Lite2 - A lightweight, efficient object detection model optimized for real-time performance

Configuration

Centralized configuration system allows customization of detection classes, thresholds, intervals, and action functions. Use the Config Generator to create or tweak config.js in the browser and the Config Manager to list, view, and delete configs in config/public.

Architecture

Modular design with separate client modules and shared library functions for recognition, actions, and visualization

API Integration

Optional OpenAI GPT-4 Vision API integration for advanced image description and analysis capabilities
