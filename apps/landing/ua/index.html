Огляд системи

Vision System — комплексна платформа розпізнавання об'єктів на основі сучасних моделей машинного навчання для виявлення та ідентифікації об'єктів у потоках з камер у реальному часі та на статичних зображеннях. На базі моделі MediaPipe EfficientDet Lite2 система забезпечує точне, швидке та налаштовуване розпізнавання.

Платформа має модульну архітектуру: зручне налаштування класів детекції, порогів і власних дій. Підтримується обробка в реальному часі з камер і пакетна обробка завантажених зображень — для моніторингу, аналізу контенту та автоматичного відстеження об'єктів.

Ключові можливості

  • Розпізнавання в реальному часі: обробка відео з камери з налаштовуваними інтервалами
  • Пакетна обробка зображень: завантаження з файлів або URL для аналізу
  • Серверне розпізнавання: API (Puppeteer + MediaPipe) та перегляд результатів у браузері
  • Серверне міркування: зображення та запит до AI (ChatGPT або Gemini) з відповіддю в браузері
  • Налаштовувані класи: вибір типів об'єктів (люди, транспорт, тварини тощо)
  • Візуалізація рамок: bounding boxes і підписи за потреби
  • Система дій: власні функції за результатами детекції
  • Інтеграція OpenAI: опційний опис зображень через AI
  • Модульна архітектура: легко розширювати під конкретні задачі
  • Навчання моделей: UI для підготовки детекції та fine-tuning VLM, розподілу датасету та графіків метрик (навчання, збережені моделі)

Генератор конфігів (розширений)

Відкрити розширений

Розширений інтерфейс

Той самий збірник config.js з ширшим макетом: фільтр секцій форми, попередній перегляд конфігу, тип edge-платформи та закріплені кнопки генерації. Завантаження та збереження на сервері — як у звичайному генераторі.

Генератор конфігів

Відкрити генератор

Створення та налаштування config.js

Веб-інструмент для збирання config.js Vision v4 без ручного редагування: класи детекції, пороги, модель, API та інше — форма, копіювання або завантаження файлу.

Можливості:

  • Розпізнавання: класи (людина, собака, авто тощо), поріг, інтервал
  • Модель: шлях до ресурсу, delegate (GPU/CPU), поріг score
  • API: базовий URL і промпт для опису зображення у стилі OpenAI
  • Опції: додаткові параметри рантайму та відображення
  • Експорт: копія або завантаження config.js

Сценарії:

  • Швидкий старт нового розгортання Vision v4
  • Експерименти з класами та порогами
  • Конфіги для dev / staging / production

Навчання моделі

Дашборд моделей Навчання

Детекція та fine-tuning зорово-мовних моделей

Застосунок /model-training — підготовка до навчання розпізнавання та VLM: базова модель зі списку, зображення з файлами анотацій, розподіл train / validation / test, гіперпараметри, запуск із графіками метрик (loss, mAP, precision/recall, learning rate, час). Дашборд збережених моделей (/model-training/dashboard) — список checkpoint-ів у db/models та видалення через API сервера v4.

Можливості:

  • UI навчання: базові моделі, датасет, спліти, гіперпараметри, метрики, експорт або збереження checkpoint
  • Дашборд: файли .pt / .tflite / .safetensors у db/models; видалення
  • Завантаження: зображення та анотації; співставлення за іменем файлу
  • Спліти: train / val / test на рядок або авто-пресети
  • Запуск: епохи з оновленням графіків

Сценарії:

  • Прототип операторського UI перед підключенням реального тренера
  • Керування збереженими checkpoint після збереження з дашборду
  • Разом із VIA та завантаженням зображень

Збереження checkpoint і дашборд потребують Node-сервер v4. Підключіть бекенд-тренер замість клієнтського циклу за потреби.

VIA Image Annotator

Запустити анотатор

Ручна анотація зображень, аудіо та відео

У пакеті — VGG Image Annotator (VIA) у варіанті для зображень: автономний HTML/JS/CSS інструмент для міток на медіа в браузері без окремого встановлення. На цьому хості доступний за шляхом /annotate.

Можливості:

  • Медіа: локальні файли або URI file:// / http://, масове введення URI, тип Image / Video / Audio / auto
  • Просторові регіони: прямокутні рамки на зображеннях і кадрах відео (на паузі)
  • Часові сегменти: інтервали на аудіо та відео
  • Атрибути: редактор атрибутів регіонів
  • Імпорт / експорт: VIA3 (CSV), тільки сегменти (CSV), COCO; імпорт shared project або VIA2 JSON
  • Гарячі клавіші: пробіл — play/pause; n / p — наступне/попереднє зображення; повний список у довідці застосунку

Сценарії:

  • Ground truth для датасетів і оцінки моделей
  • Маркування перед перевіркою в завантаженні зображень або порівнянні

Завантаження зображень

Відкрити модуль

Аналіз статичних зображень

Завантаження файлів або зображень за URL, детекція об'єктів, рамки та завантаження анотованого зображення.

Можливості:

  • Файл: JPG, PNG з пристрою
  • URL: віддалене зображення
  • Один прохід: аналіз за кнопкою
  • Візуалізація: рамки та впевненість
  • Завантаження: зберегти результат з рамками
  • Дії: власні функції за результатами

Сценарії:

  • Пакетний аналіз зображень
  • Модерація контенту
  • Анотування та маркування
  • Контроль якості та верифікація об'єктів
  • Дослідження та збір даних

Послідовність:

  1. Обрати файл або ввести URL
  2. Натиснути «Recognize» для детекції
  3. Переглянути рамки
  4. За потреби завантажити результат

Серверне розпізнавання

Відкрити модуль

Детекція через API сервера

Зображення з файлу або URL; обробка на сервері розпізнавання (Puppeteer + MediaPipe), відображення рамок, завантаження анотованого JPG.

Можливості:

  • Файл або URL: завантаження з пристрою або мережі
  • Сервер: без моделі в клієнті
  • Візуалізація: рамки та підписи
  • Завантаження: зберегти результат як JPG

Сценарії:

  • Винесення навантаження на окремий сервер
  • Тест API розпізнавання з браузера
  • Разова або пакетна обробка без завантаження моделі в клієнт

Вимоги:

  • Запущений сервер розпізнавання (наприклад npm run recognize або окремий процес на заданому порту)

Серверне міркування

Відкрити модуль

AI-міркування над зображеннями

Зображення та текстовий промпт на сервер; ChatGPT (OpenAI) або Gemini повертають текстову відповідь. Оберіть модель, введіть запит і завантажте зображення.

Можливості:

  • Зображення + промпт: питання або запит на аналіз
  • Модель: ChatGPT (наприклад gpt-4.1-mini) або Gemini (наприклад gemini-3-flash-preview)
  • Сервер: зорово-мовне міркування через OpenAI або Google API
  • Відповідь: текст у браузері

Сценарії:

  • Опис, підпис або Q&A щодо зображення
  • Візуальний аналіз без моделі в клієнті
  • Тест API POST /api/reasoning

Вимоги:

  • Головний сервер v4 (reasoning — частина того ж сервера)
  • OPENAI_API_KEY та/або GEMINI_API_KEY у .env

Порівняння

Відкрити порівняння

Локальне та серверне розпізнавання й міркування

Одне зображення: локальна детекція (YOLO або MediaPipe), серверне розпізнавання та серверне міркування (ChatGPT або Gemini) — результати поруч на одному екрані.

Можливості:

  • Одне зображення: усі панелі використовують його
  • Локально: YOLO або MediaPipe у браузері
  • Сервер: детекція через API та рамки
  • Міркування: ChatGPT або Gemini, текстова відповідь
  • Поруч: порівняння локальної та серверної детекції й міркувань

Сценарії:

  • Порівняння локальної та серверної детекції на тому ж зображенні
  • Розпізнавання та міркування без перемикання застосунків
  • Оцінка моделі або API одним завантаженням

Демо продакшн

Гнучка конфігурація
Запустити демо

Гнучка конфігурація функціональності — веб-версія

Односторінкове демо повного vision-конвеєра в браузері на config-factory.js. Перемикання YOLO та MediaPipe, керування розпізнаванням і періодичними діями, UI — усе з одного конфігу.

Можливості:

  • Керування конфігом: поведінка в config-factory.js (класи, пороги, модель, дії)
  • Дві моделі: YOLO або MediaPipe для локальної детекції
  • Потік з камери: живе відео з рамками та інтервалом розпізнавання
  • Локальні дії: дії при розпізнаванні та періодичні дії з обмеженням частоти
  • Опційний UI: кнопки через config.ui; headless для автоматизації

Сценарії:

  • Ознайомлення з платформою на еталонному конфігу
  • Перевірка змін конфігу перед розгортанням в інших модулях
  • Демо та тестування веб-версії з гнучкою конфігурацією

Через генератор конфігів або розширений генератор зібрати config.js, замінити config-factory.js або вказати свій конфіг. Менеджер конфігів — перегляд і видалення файлів у db/configs/public.

Потік з камери

Запустити камеру

Розпізнавання об'єктів у реальному часі

Безперервна детекція з відеопотоку камери пристрою з накладанням bounding boxes на відео.

Можливості:

  • Живе відео: потік камери як фон
  • Безперервне розпізнавання: детекція з налаштовуваним інтервалом (типово 500 мс)
  • Ручне розпізнавання: один прохід за запитом
  • Рамки в реальному часі: об'єкти та впевненість
  • Дії при розпізнаванні: власні функції за результатами
  • Періодичні дії: незалежно від циклів детекції

Сценарії:

  • Безпека та спостереження
  • Підрахунок людей і трекінг
  • Наявність об'єктів у кадрі
  • Інтерактивні застосунки з візуальним фідбеком

Керування:

  • Увімкнути камеру: показати потік
  • Вимкнути камеру: зупинити та звільнити ресурси
  • Почати розпізнавання: безперервна детекція
  • Зупинити розпізнавання: пауза, камера активна
  • Ручне розпізнавання: один прохід по поточному кадру

Багатопотоковий WebRTC

Відкрити стрімінг

WebRTC: захоплення кадру та розпізнавання

Кілька відеопотоків WebRTC з камер пристроїв або URL відео, перегляд на одній сторінці, захоплення кадрів для детекції YOLO або MediaPipe — усе в браузері через P2P.

Можливості:

  • Потоки з камери: сторінки стрімера з трансляцією через WebRTC
  • Потоки з URL: відеофайл (MP4, WebM) замість камери
  • Мультиперегляд: кілька потоків поруч на одній сторінці перегляду
  • Захоплення та розпізнавання: кадр з потоку, модель, bounding boxes
  • Вибір моделі: YOLO або MediaPipe для захопленого кадру
  • QR-коди: швидке відкриття стрімера на мобільному

Сценарії:

  • Мультикамерний моніторинг із детекцією за запитом
  • Стрімінг файлу та аналіз окремих кадрів
  • Віддалений доступ до камери через QR
  • Порівняння результатів з різних ракурсів

Послідовність:

  1. Ввести ID потоку (за потреби URL відео) на головній і відкрити стрімер
  2. Запустити камеру або відео на сторінці стрімера
  3. Обрати активні потоки та відкрити переглядач
  4. «Capture», модель, перегляд детекції
